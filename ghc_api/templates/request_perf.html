    Metric definitions and limitations

    Effective TPS = total output tokens / total duration, for successful completed requests with positive output and duration. It includes first-token wait. Errors, cancellations, unknown status, and zero-output calls are excluded from speed metrics, but remain in request counts and duration totals.

    Context totals and cache share use only requests with a valid context total. Missing optional cache fields may be zero; explicitly invalid components make the context unavailable, without discarding the request's other metrics.

    Measured TTFT is the mean of valid persisted ttft values on successful requests. Decode TPS uses only generating requests with duration > ttft: total output / total (duration − ttft). Missing timing is never treated as zero.

    Estimated timing fits duration ≈ TTFT + output / decode TPS using at most 90 reservoir samples per day/model and at most 220 points per fit. Fits require at least 10 samples and a positive slope. This is a rough trend indicator, not a reconstruction of actual first-token times. Daily samples and changing request mix can bias multi-day estimates. Measured and estimated trend series are separate.

    Approximate percentiles interpolate within 48 logarithmic bins (duration: 0.05–3000 s; TPS: 0.5–400). Out-of-range values are clipped to end bins and counted in data-quality notices. Totals and measured means are not histogram estimates.

    Failures / cancellations are disjoint; the displayed combined rate counts each request once. Status 499 is cancellation, not an additional failure. Unknown status is shown separately. Cumulative request time is a sum across requests, not elapsed wall-clock time when requests overlap.

    Source JSONL is parsed normally; malformed and oversized lines are skipped and counted, never recovered with regex. Partial trailing lines wait for the next scan. Dates and hours use the server's local timezone; missing timestamps fall back to the source file date without inventing an hour. No external chart libraries or network services are used.
